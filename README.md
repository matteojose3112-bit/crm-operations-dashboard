## Overview

The CRM Operations Dashboard is a business intelligence dashboard designed to simulate a modern CRM reporting environment used by Sales Operations and Revenue Operations teams.

The project transforms structured customer and sales data into actionable insights through pipeline visibility, revenue tracking, opportunity management, and operational reporting.

---

## Key Features

✅ Dynamic CRM data loading  
✅ Sales pipeline visualization  
✅ Revenue KPI tracking  
✅ Opportunity monitoring  
✅ Customer activity insights  
✅ Interactive charts  
✅ Data filtering  
✅ Search functionality  
✅ Responsive dashboard design
